  - Names: the diagnosis names every one, the plan names every one
- Run 3 diagnosis: shop-worker wird durch OOM beendet, weil WORKER_BATCH_MB auf 256 MB steht, während der Container nur ein Speicherlimit von 64.0 MiB hat. Die Deploy-Dokumentation nennt 8 MB als Standardwert für WORKER_BATCH_MB.
