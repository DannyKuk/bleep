List the environment variable keys a Coolify application has, with whether each is used at build time, at run time or in previews. Values are never shown. Use it when a setting may be missing or misnamed. A coolify.set_env takes effect only at the next deployment, so a plan that sets one redeploys the application after it. `app` is the application's uuid or name from coolify_applications. {untrusted_rule}
