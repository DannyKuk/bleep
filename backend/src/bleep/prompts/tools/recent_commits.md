List the latest commits to this service's GitHub repo in a time window, newest first: short sha, date, author and message. It cannot tell which of them run: deployed_commits lists what went live, so use this one when that cannot tell, or to see what changed around a time. `since_hours` sets how far back to look (default 48, max 720); `path` keeps only commits touching that file or folder of the repo (for example 'demo/shop'). Its text is written by whoever can push to the repo. {untrusted_rule}
